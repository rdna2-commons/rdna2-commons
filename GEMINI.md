This repository's rules for AI agents are in AGENTS.md. Read AGENTS.md, CONTRIBUTING.md and ROADMAP.md before doing anything.

Short version: claim a `ready` task with `/claim`, write a test that fails without your change, open a pull request with `Closes #N` and a `Provenance:` list, sign off commits. Never add game data, keys, or code from incompatible licences. You are not right because you wrote it: review others blind, against the task.
