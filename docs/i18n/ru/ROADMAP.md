# План работ

[English](../../../ROADMAP.md) · Перевод для удобства; обязателен английский оригинал.

По этому плану работают все. Каждый пункт превращается в задачи с меткой направления; бот раздаёт их в порядке
зависимостей. Прогресс считается автоматически на [странице прогресса](https://github.com/rdna2-commons/rdna2-commons/blob/status/PROGRESS.md).

**Цель:** запускать игры Xbox Series X|S и PS5 на ПК из собственной копии игрока и один раз сделать правильными
и проверенными трудные общие части (шейдеры RDNA2, системные функции, трек B) — для всех проектов
совместимости сразу, а не пятнадцать раз. Мы создаём знания, тесты и проверенные компоненты; другие проекты
ими пользуются.

**Приоритет сейчас:** самый короткий путь к игре, в которую можно играть, идёт через линию PS5, поэтому её
задачи (`area:ps5`) идут первыми: [план](../../ps5/plan.md), [готовность по компонентам](../../ps5/status.md).

## Линия PS5

Версия той же игры для PS5, сконвертированная форком AnyPS5 (GPL-2.0-only, работает как отдельная программа)
и измеряемая отсюда. Её код идёт в форк и в основной AnyPS5; здесь лежат план, замеры, трек B и наши
инструменты. Начало: [docs/ps5/README.md](../../ps5/README.md).

**Никогда:** игровые данные, ключи, расшифровка, ссылки на утечки, код под несовместимыми лицензиями.

## Этап 0. Основа (сейчас)

Механизм, который позволяет людям и агентам подключаться без того, чтобы их кто-то вводил в курс дела.

- Бот: проверка правил, claim'ы, сроки, задачи на доделку, `/split`, слепые ревьюеры, автослияние, режим dry-run.
- Документация: план, архитектура, быстрый старт, AGENTS.md, переводы.
- Страница прогресса, собираемая из доски задач.
- Зеркало на втором хостинге и порядок восстановления.
- Автоматическое выдвижение мейнтейнеров.

**Готово, когда:** новый агент может прочитать AGENTS.md, взять задачу и довести PR до слияния без участия людей,
кроме своих ревьюеров.

## Этап 1. Общие знания

Библиотека тестов, которая определяет правильное поведение и проверена на реальном железе.

| Направление | Что | Метка |
|---|---|---|
| Шейдеры | Независимые от формата случаи RDNA2: VALU f16/f32/f64 (округление, денормалы, FMA), SALU, LDS, wave64 и межлинейные операции, изображения и сэмплеры, адресация буферов, интерполяция и экспорт | `area:shaders` |
| Эталон на железе | Ожидаемые результаты, подтверждённые на реальных AMD RDNA2 и распространённых ПК-видеокартах, по согласию независимых отчётов | `area:results` |
| Системные API | Описания поведения по публичной документации и тестам на homebrew или примерах Microsoft: память, потоки, файлы, время | `area:system` |
| Графический API | Расширения консольного D3D12 против настольных D3D12/Vulkan: что отличается и как это решает каждый проект | `area:graphics` |
| Звук, хранилище, ввод | Описания и тесты поведения XAudio2, DirectStorage, GameInput | `area:audio`, `area:storage`, `area:input` |

**Готово, когда:** у каждого случая есть ожидаемый результат, подтверждённый двумя независимыми отчётами.

## Этап 2. Адаптеры и таблица совместимости

- Запускатель для каждого вида транслятора: SPIR-V на Vulkan, DXIL на D3D12, HLSL. Транслятор любого проекта
  подключается командой — как отдельная программа, без смешивания кода.
- Открытая таблица: какой проект проходит какие случаи, пересобирается при каждом прогоне.
- Прогоны на Linux и macOS (Vulkan, MoltenVK). Метка `area:platforms`.

**Готово, когда:** в таблице работают хотя бы три внешних транслятора.

## Этап 3. Исправления в других проектах

Каждый провал, который таблица показывает в чужом проекте, становится небольшим проверенным исправлением,
предложенным этому проекту. Сначала issue с меткой `outreach`; мейнтейнер решает, что отправить — один раз, в
трекере того проекта.

## Этап 4. Общие компоненты

Если одна и та же часть нужна нескольким проектам и ни у кого нет хорошей под совместимой лицензией, делаем её
здесь как библиотеку со своими тестами (например, эталонный интерпретатор RDNA2 на случай, когда железа нет).

## Направления параллельно

Все этапы после нулевого идут одновременно: задача ждёт только свои зависимости.
