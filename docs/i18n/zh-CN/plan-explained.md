# 用大白话讲计划

[English](../../plan-explained.md)

**问题是什么。** 主机游戏是为主机的处理器、显卡和系统编写的程序。Xbox Series 的处理器和 PC 是同一类，所以程序的大部分
本可以直接在 PC 上运行。阻碍有两点：绘制画面的小程序（着色器）是为主机的 AMD 显卡写的；游戏调用的系统功能（内存、文件、
声音、手柄）在 Windows 上不存在。每个兼容项目都要翻译这两部分，而且都在各自为战。

**我们的做法。** 用测试把主机的行为精确地写下来：“这条指令配这些输入，得到这些输出”。多人在真实硬件上运行这些测试，
只有结果一致才算数。之后任何项目都可以用这些测试检查自己的翻译器，逐行看出哪里错了。

**各阶段**

0. **基础** —— 规则、检查每份贡献的机器人、文档。新人（人类或 AI）能独立领取任务并被接受时完成。
1. **共享知识** —— 各方向的测试本身：图形指令、内存、声音、存储、手柄。每个测试都有两人独立确认的结果时完成。
2. **适配器** —— 用我们的测试运行其他项目翻译器的小连接器，以及一张“谁通过了什么”的公开表格。
3. **上游修复** —— 表格发现其他项目的错误时，我们向该项目提供修复。
4. **共享组件** —— 多个项目都需要、却没人做的部分，在这里做成库。

从阶段 1 开始，一切并行：每个任务只等待它所依赖的任务。

**我们绝不做的事：** 分享任何游戏内容（文件、代码、图片、声音）、破解保护、链接泄露内容。我们测试的一切都是专门手写的。

**如何关注：** [进度页](https://github.com/scarlett-commons/scarlett-commons/blob/status/PROGRESS.md)每六小时自动更新。
每个任务都是 GitHub 上的一个 issue，任何人都可以领取。
