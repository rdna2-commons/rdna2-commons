# Security and legal reports

- **Game data, keys or a link to a leak slipped in?** Open an issue titled `removal:` with the path or link (do
  not quote the content). Any maintainer removes it first and discusses after. For something that must not stay
  public even for minutes, use GitHub's private vulnerability reporting on this repository instead.
- **A DMCA or other legal notice:** send it to GitHub through its normal process; maintainers comply with the
  named content at once (GOVERNANCE.md).
- **A hole in the bot or a workflow** (a way to merge without review, run pull request code with a write
  token, or bypass the game-data guard): use private vulnerability reporting, not a public issue.
